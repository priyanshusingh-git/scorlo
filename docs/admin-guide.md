# Other Admin Guide

## Who this guide is for

This guide is for delegated admins, not the main admin.

## Available sections

Other admins have access to:

- Students
- Issues
- Profile

They do not have access to:

- Overview
- Admin account management
- Users
- Maintenance

## Students

The Students area lets you:

- search academic student records
- filter the student table
- page through records
- open a student profile

Inside a student profile you can review:

- core identity details
- branch and batch
- roll number
- academic metrics
- semester history
- ranks

## Issues

The Issues area lets you:

- review student-submitted support issues
- update issue status
- add admin notes

Use it for:

- wrong data
- missing records
- link problems
- account issues

## Profile

Shows your own admin account details, including:

- name
- email
- role
- email verification state

## Important limits

Other admins cannot:

- create admins
- delete the main admin
- access maintenance
- perform main-admin-only destructive actions

These restrictions are enforced by the server, not only by navigation visibility.
